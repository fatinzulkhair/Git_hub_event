# =============================================================================
# seed_validation_rules.py  ->  POST /validation-rules  format
# =============================================================================
# Every rule defined in seed_validation_rules.py, rewritten as the JSON the
# POST /validation-rules endpoint accepts (camelCase aliases: ruleId,
# validationType, onExceptionStatus, field, dataType, ...).
#
# Usage:
#   * POST a single rule_* object                -> creates that one rule
#   * POST ACTIVE_RULES_PAYLOAD (bottom)         -> recreates the current seed
#
# Notes:
#   - "conditions" form and "checkId"/"check" form are interchangeable for a
#     single-field Data-Type / Operator test; IF/THEN/ELSE needs checks + logic.
#   - Field names are matched case-insensitively by the engine.
# =============================================================================
